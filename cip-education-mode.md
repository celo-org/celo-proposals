## Simple Summary
Introduce an “Education Mode” in Celo SDK, offering simplified tools and examples for teachers and students to learn blockchain and smart contracts through hands-on activities.

## Abstract
This proposal suggests adding an educational configuration to the Celo SDK that includes pre-built templates, demo smart contracts, and a simplified user interface designed for learning environments.

## Motivation
Currently, teachers and young learners face technical barriers when exploring blockchain coding. Celo’s friendly mission can be expanded by providing a guided learning version of SDK to make blockchain education accessible in schools.

## Specification
- Add a new “education” configuration flag in SDK.
- Include pre-written contract templates (token, voting, and mediation examples).
- Enable a simplified CLI output (with human-friendly explanations).
- Provide documentation targeted at teachers and beginners.

## Rationale
This change lowers the entry barrier for educators and encourages adoption of blockchain technology in formal education environments.

## Risks
- Additional maintenance load.
- Possible complexity in merging educational templates with production SDK.
